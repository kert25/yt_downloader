# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/),
проект следует [Semantic Versioning](https://semver.org/).

---

## [v0.2.0] — 2026-05-24

### Added

- Система конфигурации пользователя (config.py + config.json)
- Настройки в интерфейсе: формат по умолчанию, качество, папка загрузок, автоочистка
- Выбор качества видео в форме загрузки (360p / 480p / 720p / 1080p / max)
- `/api/config` — эндпоинт для чтения и сохранения настроек
- `config.py` — модуль загрузки/сохранения конфигурации

### Changed

- `/download` теперь принимает параметр `quality` и читает умолчания из конфига
- Автоочистка старого кода теперь использует настройки из конфига

## [v0.1.0] — 2026-05-24

Первый рабочий билд — минимально жизнеспособный продукт.

### Added

- Загрузка видео с YouTube в формате MP4 (до 1080p)
- Загрузка аудио с YouTube в формате MP3 (192 kbps, через ffmpeg)
- Веб-интерфейс на Flask (одна страница: поле ввода ссылки, выбор формата, кнопка скачивания)
- Автоматическая очистка временных файлов после скачивания
- Модальное окно с подтверждением завершения скачивания
- Обработка ошибок с выводом понятного сообщения в интерфейсе
- Статическая сборка ffmpeg в `bin/` для работы MP3 без системной установки
- `README.md` с инструкцией по установке и запуску
- `.gitignore` для исключения venv, кешей и временных файлов
