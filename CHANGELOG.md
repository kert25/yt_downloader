# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/),
проект следует [Semantic Versioning](https://semver.org/).

---

## [v0.2.3] — 2026-05-24

### Added

- Прогресс-бар с процентом и описанием операции (скачивание/обработка)
- Кнопка «Отменить» для прерывания активной загрузки
- Прогресс теперь отслеживается через бэкенд (фоновый поток + polling)
- При завершении файл автоматически скачивается в браузер + модалка

### Changed

- `/download` теперь асинхронный — возвращает `download_id`, файл отдаётся через `/file/<id>`
- Новые эндпоинты: `/progress/<id>` (опрос статуса), `/cancel/<id>` (отмена)

## [v0.2.2] — 2026-05-24

### Fixed

- **XSS**: ошибки с пользовательским вводом теперь экранируются (HTML entities)
- **XSS**: статус-бары используют `textContent` вместо `innerHTML`
- **Path traversal**: `download_path` проверяется на `..` и абсолютные пути
- **Валидация**: качество, формат и часы очистки проверяются по whitelist
- **Debug mode**: выключен по умолчанию, включается через `YT_DEBUG=1`
- **Secret key**: генерируется случайный ключ для Flask
- **Таймауты**: socket_timeout=30с, max_filesize=4GB

## [v0.2.1] — 2026-05-24

### Changed

- Полный редизайн: одна страница без табов, двухколоночный макет
- Настройки всегда видны в правой колонке
- Качество скрыто при выборе MP3 (аудио)
- Убраны подписи колонок, субтитр, неиспользуемые кнопки и поля
- Левая панель скачивания растянута на полную высоту — колонки теперь ровные

### Removed

- Кнопка «Сброс» настроек
- Поле «Папка загрузок» из UI (бесполезно для пользователя)
- Вкладки «Скачать/Настройки» (всё на одном экране)

## [v0.2.0] — 2026-05-24

### Added

- Система конфигурации пользователя (config.py + config.json)
- Настройки в интерфейсе: формат по умолчанию, качество, папка загрузок, автоочистка
- Выбор качества видео в форме загрузки (360p / 480p / 720p / 1080p / max)
- `/api/config` — эндпоинт для чтения и сохранения настроек
- `config.py` — модуль загрузки/сохранения конфигурации

### Changed

- `/download` теперь принимает параметр `quality` и читает умолчания из конфига
- Автоочистка старого кода теперь использует настройки из конфига
- Полный редизайн интерфейса: табы «Скачать» и «Настройки», переработанная сетка, новая цветовая схема

## [v0.1.0] — 2026-05-24

Первый рабочий билд — минимально жизнеспособный продукт.

### Added

- Загрузка видео с YouTube в формате MP4 (до 1080p)
- Загрузка аудио с YouTube в формате MP3 (192 kbps, через ffmpeg)
- Веб-интерфейс на Flask (одна страница: поле ввода ссылки, выбор формата, кнопка скачивания)
- Автоматическая очистка временных файлов после скачивания
- Модальное окно с подтверждением завершения скачивания
- Обработка ошибок с выводом понятного сообщения в интерфейсе
- Статическая сборка ffmpeg в `bin/` для работы MP3 без системной установки
- `README.md` с инструкцией по установке и запуску
- `.gitignore` для исключения venv, кешей и временных файлов
